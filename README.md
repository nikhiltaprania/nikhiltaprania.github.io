## Tech Stack (this site)

Built as a lightweight, dependency-free static site — no framework or build step.

- **HTML5** — semantic markup
- **CSS3** — custom properties, responsive (mobile-first) layout, light/dark theme
- **Vanilla JavaScript** — navigation, theme toggle, scroll-spy
- **[ScrollReveal](https://scrollrevealjs.org/)** — on-scroll animations
- **[EmailJS](https://www.emailjs.com/)** — contact form delivery
- **[Remix Icon](https://remixicon.com/)** — icon set
